Required software
-----------------
Python 3.12.14; NumPy 2.3.5; SciPy 1.17.0. Use a Linux x86-64 system for
the supplied binaries. The kernel extension requires OpenSSL libcrypto.
The original interpreter/runtime and OS are not included as a virtual machine
or a complete virtual environment. Dependencies are installed from the pins.
For a local native rebuild, install a C compiler, Python development headers,
OpenSSL development headers and libcrypto. On Debian-like systems these are
normally supplied by build-essential, python3.12-dev and libssl-dev.

Prepare a clean Python environment
---------------------------------
Extract this run bundle into a new directory, then execute:

  python3.12 -m venv .venv
  . .venv/bin/activate
  python -m zipfile -e SOURCE_FOR_REPLAY.zip archived_sources
  python -m pip install -r archived_sources/engine/requirements.txt

Verify the archived run using its exact archived source and binaries
------------------------------------------------------------------
Do NOT rebuild or edit archived_sources before this check. A rebuild can
change binary bytes and therefore the archived kernel identity.

  python -B archived_sources/engine/run.py --out eps_3em4 --through 18 --epsilon 3e-4 --verify-layer 18

To recheck every layer, repeat with --verify-layer 1 through 18. The verifier
checks the exact code/runtime identity, parent receipt lineage, payload hashes
and recorded comparisons. It is an artifact verification, not an independent
recomputation of every physical trajectory or a new mathematical proof.

If the archived binaries cannot load on the target OS, or code/runtime identity
does not match, keep the archived campaign untouched. It cannot be accepted
under a changed environment by editing campaign.json or copying receipts.

Start an independent fresh calculation on your machine
----------------------------------------------------
Create a SECOND source copy for rebuilding, separate from archived_sources:

  python -m zipfile -e SOURCE_FOR_REPLAY.zip fresh_sources
  cd fresh_sources/engine
  python -B build_all_native.py
  python -B -m unittest discover -s tests --failfast
  python -B launch_fresh.py --out ../../fresh_eps_3em4 --workers 8 --memory-mib 1536 --cpu-seconds 14400 --epsilon 3e-4

The fresh output directory must not exist. The runner generates its own new
campaign.json and run identity. Never edit or reuse the archived receipts.
For the other sweep values, use --epsilon 1e-3, 3e-3 or 1e-2, each with a new
output directory. Physical uncertainty is relative +/-epsilon; initial-state
uncertainty remains delta=1e-5.
