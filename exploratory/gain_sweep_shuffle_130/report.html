A22 — Fixed gains from the outset and shuffled learned gains

1471 completed network evaluations. 130 layers, 12 lanes, 128 source pulses. Twenty network seeds at each of three noise levels, plus deterministic controls without noise.

Two questions. Can manually chosen, uniform, static gains transmit the word? Does the placement of the learned gains matter, beyond their distribution? These tests address the need for gain learning and learned spatial assignment under the specified protocols.

Main findings

  • Uniform gain 4 with b fixed at its nominal 0.08 transmits the entire 128-pulse word on all twelve lanes in 20/20 seeds at each noise level, with no gain or b adaptation.
  • With the original b-learning rule retained, the smallest evaluated gains achieving 20/20 complete words are 1.8 (low noise), 2 (medium) and 3 (high). These are grid observations, not universal thresholds.
  • The unchanged learned frozen reference achieves 19/20, 20/20 and 19/20 complete words at low, medium and high noise. Shuffling within layers, with or without preserving each port distribution, yields 0/40 complete words per level. Keeping the first six layers unchanged improves the tail-shuffle scores to 6/40, 8/40 and 3/40, but remains below the learned reference.
  • The learned assignment is useful at its existing gain distribution. Learning is not necessary for this finite transmission task when sufficiently large uniform gains can be manually assigned. This separates the ability to transmit from autonomous parameter acquisition.

Uniform gains fixed from t = 0

All 4,680 connection gains are assigned the same value before the first input and remain bitwise unchanged throughout the 128-pulse word. There is no gain-training phase. The primary control starts with q = 0.1 and b = 0.08 and retains the original b-update rule. Therefore, successful primary controls establish that gain adaptation is unnecessary for that task with those hand-set parameters; b can still adapt.

The existence of working hand-set parameters does not explain how a network finds those parameters autonomously from the nominal initialization. It is evidence against a universal claim that learning is required for transmission, while leaving the acquisition problem open.

Shuffling learned gains

The reference uses the supplied normal 2,048-pulse learned checkpoints. Gains and b are frozen, and q relaxes analytically over 3,080 time units before the test. There is no gain substitution into an untrained learning history: this is a direct perturbation of the learned parameter assignment. Every shuffled branch retains the original b at each cell and the same quiet-state preparation.

  • Within layer: shuffle the 36 scalar gains within each layer.
  • Within layer and port: independently permute the twelve lane gains for each layer and port, preserving port-specific distributions.
  • Tail within layer: shuffle within layers 7–130 while keeping layers 1–6 unchanged, to separate deeper assignment effects from a broken initial propagation front.

Each mode uses two independent permutation draws per network seed. Every mode preserves the complete gain multiset and each layer’s gain multiset exactly. All conditions reuse the same test-noise field. Shuffling gains while retaining b can also break learned gain–b associations; degradation alone does not isolate a unique spatial mechanism.

Interpretation and limits

A successful uniform fixed-gain network demonstrates an alternative way of solving this finite transmission task. If shuffled learned gains lose fidelity, this supports the usefulness of their assignment at the learned gain distribution; it does not establish that this assignment is the only workable one. Conversely, successful shuffles weaken evidence for a requirement for that precise assignment.

The pre-specified gain grid was not refined after seeing results. Choosing the best point from this sweep is exploratory and requires fresh evaluation seeds for claims about a selected design’s reliability. Twenty successes out of twenty still give an exact two-sided 95% binomial lower bound of approximately 83.2%, rather than certainty. Bootstrap intervals can collapse at perfect outcomes and should not be interpreted as universal guarantees. No multiple-testing significance claims are made.

The two permutation draws for one seed are correlated evaluations of the same learned network. Continuous scores and paired comparisons first average the draws within seed, then bootstrap the twenty seeds. A 40-draw success count is descriptive, not forty independent network replicates. The quiet controls have one deterministic network; their two shuffle draws are not independent training replicates.

Protocol, validation and audit

The source is a single lane. The 128-pulse source starts at time zero with irregular gaps 20 × (1, 1.1, 1.05, 1.2, 1, 1.15). Noise multiplies each transmitted pulse by exp(σZ − σ²/2), with σ = 0.05 / 0.10 / 0.15; centered uniform timing jitter has standard deviation 0.015 / 0.030 / 0.045, with nominal delay 0.1. A new counter-field stage 7001 and labels 2000000+i separate these tests from earlier training and evaluations. Perturbations are paired by seed, layer, lane, port, label and occurrence. Source labels identify exact recovery; the full-word score also requires order and no extra events on all twelve output lanes.

Audit: 1471 complete files; 1471 final output-event lists independently recounted; 366 verified shuffles; 0 audit errors. Gain immutability is asserted for every cell in every run, as is b immutability for fully frozen conditions. Four reference comparisons give exact full-JSON identity with the preceding kernel, including frozen learned states and fixed uniform parameters. A separate check verifies unchanged gains with nonzero b adaptation.

The supplied normal_2_9.states checkpoint had been truncated; this package uses the documented reconstruction from the complete original JSON states. All 1,547 complete original rows and the two surviving fields of the next row matched exactly. No seed is dropped. INPUT_REPAIR.json records the repair.

This is the supplied numerical point simulator, not a certified engine. All results are finite-horizon and specific to the tested graph, pulse family, initial parameters and perturbations. No energy validation or universal necessity theorem is claimed.

Reproduce

Requirements: Python 3, NumPy, Matplotlib, and g++ C++17. Compile g++ -O3 -std=c++17 -ffp-contract=off src/control.cpp -o control, then run python run.py, python analyze.py and python report.py. Existing completed results are reused. Move results/ to recalculate. Permutation indices, learned inputs, raw output events, layer profiles, validation evidence, protocol and source code are included. Paired exploratory bootstrap comparisons are in summary.json; per-realization metrics are in metrics.csv. For validation, compile validation/reference/control.cpp into validation/reference_control before running validate.py.
